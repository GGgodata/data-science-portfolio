# Income Scout — סוכן יומי לאיתור רעיונות הכנסה

מערכת סוכנים שרצה כל בוקר, סורקת עשרות מועמדים בכמה תחומים במקביל,
הורגת את רובם, ומחזירה **2–3 רעיונות** עם תוכנית ביצוע מלאה — מהרעיון ועד המספרים.

**המדד היחיד: צורך אמיתי מוכח בראיות.** אין ראיה — אין רעיון.

## המבנה

| קובץ | תפקיד |

## מה אתה צריך לעשות

**דבר אחד:** אחרי שאתה קורא דוח, כתוב שורה ב-`memory/feedback.md` —
מה עניין, מה לא, ובעיקר **למה**.
זה הדלק של המערכת. בלי משוב הסוכן ממשיך לירות באותו כיוון.

תוכל גם להוסיף שם הנחיות קבועות ("אל תציע יותר X", "החודש רק Y") —
הסוכן מתייחס אליהן כהוראה.

## הפעלה ידנית

הריצה קורית אוטומטית כל בוקר, אבל אפשר גם להפעיל ידנית:

> בצע את `income-agent/AGENT.md` — ריצת סקאוט מלאה להיום.

לריצה ממוקדת בתחום אחד:

> בצע את `income-agent/AGENT.md`, אבל הרץ רק את `agents/wildcard.md`.

## כוונון

- **התדירות מציפה?** שנה את ה-Routine לימים ספציפיים במקום כל יום.
- **הרעיונות לא מדויקים?** התשובה כמעט תמיד ב-`memory/feedback.md` — הוסף שם הנחיה.
- **סף איכות גבוה/נמוך מדי?** שנה את סף ה-70 ב-`criteria/scoring.md`.
- **תחום מוצה?** הסר את הקובץ שלו מ-`agents/` — הסבב יתאים את עצמו.
- **רוצה תחום חדש?** הוסף קובץ ל-`agents/` באותו מבנה: מנדט, איפה לצוד,
  כללי פסילה נוספים, ודגש להפצה.
