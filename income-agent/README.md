# Income Scout — סוכן יומי לאיתור רעיונות הכנסה

מערכת סוכנים שרצה כל בוקר, סורקת עשרות מועמדים בכמה תחומים במקביל,
הורגת את רובם, ומחזירה **2–3 רעיונות** עם תוכנית ביצוע מלאה — מהרעיון ועד המספרים.

**המדד היחיד: צורך אמיתי מוכח בראיות.** אין ראיה — אין רעיון.

## הדאטהבייס

הכול נשמר בפרויקט Supabase בשם **`income-scout`**: כל ריצה, כל רעיון שנבחן
(גם שנפסל), הראיות עם הלינקים, המשוב שלך, וההנחיות הקבועות.
כך הסוכן לומד לאורך זמן במקום להתחיל מאפס כל בוקר.

שלוש שאילתות שכדאי להכיר:

```sql
select * from v_pending_decisions;    -- מה ממתין להחלטה שלך
select * from v_funnel;               -- כמה מועמדים באמת נסרקו בכל ריצה
select * from v_rejection_patterns;   -- מה נדחה ולמה
```

פירוט מלא: [`db/README.md`](db/README.md).

## מה יוצא מכל ריצה — שלוש שכבות

| שכבה | מה בה | איפה |
|---|---|---|
| **החלטה** | הרעיון המוביל, ציון, הון בסיכון, ומה לעשות היום. אם אין רעיון מעל 70 — זו השורה הראשונה | פוש לנייד (טלגרם כשייפתח) |
| **סקירה** | דף ווב: משפך, כרטיס לכל רעיון עם מד ציון מול סף ה-70, המספרים, הראיות, מה נפסל | Artifact — `reports/YYYY-MM-DD.html` |
| **תיק מלא** | 14 הסעיפים, טבלאות יחידה, כל הראיות | `reports/YYYY-MM-DD.md` |

**את השכבה השנייה אתה קורא בבוקר.** השלישית קיימת רק אם אתה נכנס לעומק.

דוגמה מהריצה הראשונה: [דוח 5.8.2026](https://claude.ai/code/artifact/40e2a3c5-b4b0-4af2-9384-b69dcea279ae)

## מה אתה צריך לעשות

**דבר אחד:** אחרי שאתה קורא דוח, תן משוב — מה עניין, מה לא, ובעיקר **למה**.
הכי פשוט: תגיד לי בצ'אט ואני אכתוב לטבלאות `feedback` / `directives`.

זה הדלק של המערכת. בלי משוב הסוכן ממשיך לירות באותו כיוון.
הנחיות קבועות ("אל תציע יותר X", "החודש רק Y") נכנסות ל-`directives`
והסוכן מתייחס אליהן כהוראה שגוברת על כל כלל אחר.

## כוונון

- **התדירות מציפה?** שנה את ה-Routine לימים ספציפיים במקום כל יום.
- **הרעיונות לא מדויקים?** התשובה כמעט תמיד ב-`memory/feedback.md` — הוסף שם הנחיה.
- **סף איכות גבוה/נמוך מדי?** שנה את סף ה-70 ב-`criteria/scoring.md`.
- **תחום מוצה?** הסר את הקובץ שלו מ-`agents/` — הסבב יתאים את עצמו.
- **רוצה תחום חדש?** הוסף קובץ ל-`agents/` באותו מבנה: מנדט, איפה לצוד,
  כללי פסילה נוספים, ודגש להפצה.
