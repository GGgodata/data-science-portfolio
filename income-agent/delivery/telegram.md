# מסירה בטלגרם — מוכן, כבוי

**סטטוס: כבוי.** `api.telegram.org` חסום ע"י מדיניות הרשת של הסביבה (403 ב-CONNECT,
נבדק 2026-08-05). כל השאר בנוי. ברגע שהוסט מאושר — שלושה צעדים ועובד.

## למה טלגרם ולא מייל

קונקטור Gmail שמחובר לחשבון יודע ליצור **טיוטות** בלבד, לא לשלוח.
טלגרם הוא הערוץ הישיר היחיד שנשאר, והוא דורש **הוספת הוסט אחד** ל-allowlist —
בקשה קטנה בהרבה מפתיחת אתרי הקהילות.

---

## הפעלה — שלושה צעדים

### 1. הרשאת רשת
הוסף `api.telegram.org` ל-allowlist של מדיניות הרשת בהגדרות הסביבה
ב-Claude Code on the web.

בדיקה שזה נפתח:
```bash
curl -s -o /dev/null -w "%{http_code}\n" https://api.telegram.org/
# 200 או 404 = פתוח. 000 = עדיין חסום.
```

### 2. יצירת בוט וקבלת chat id
1. בטלגרם: פנה ל-[@BotFather](https://t.me/BotFather) → `/newbot` → קבל **token**.
2. שלח הודעה כלשהי לבוט שיצרת.
3. קבל את ה-chat id:
   ```bash
   curl -s "https://api.telegram.org/bot<TOKEN>/getUpdates" | grep -o '"id":[0-9-]*' | head -1
   ```

### 3. אחסון הסודות
**אל תשמור token בקוד ולא ב-repo.** שתי אפשרויות:

- **מומלץ** — משתני סביבה בהגדרות הסביבה: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
- לחלופין — Supabase Vault בפרויקט `income-scout`.

ואז ב-`AGENT.md` שלב 7, במקום הפוש בלבד:

```bash
curl -s -X POST "https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendMessage" \
  -d chat_id="${TELEGRAM_CHAT_ID}" \
  -d parse_mode="HTML" \
  --data-urlencode text@- <<'MSG'
<b>Income Scout · YYYY-MM-DD</b>
50 נסרקו · 4 שרדו · <b>1 מעל 70</b>

🟢 <b>שם הרעיון</b> — 73/100
₪1,160 בסיכון · 7–12 יום לשקל ראשון
<i>מה לעשות היום, במשפט אחד.</i>

🟡 רעיון שני — 66 · מתחת לסף
🟡 רעיון שלישי — 65 · מתחת לסף

📄 הדוח המלא: {{ARTIFACT_URL}}
MSG
```

## מה נשלח — כרטיס ההחלטה בלבד

הכלל: **ההודעה בטלגרם היא שכבת ההחלטה, לא שכבת הסקירה.**
מי שרוצה פירוט לוחץ על הלינק לדף.

| נכנס להודעה | לא נכנס |
|---|---|
| משפך בשורה אחת | טבלאות ראיות |
| שם, ציון, הון בסיכון, ימים להכנסה | מפות מתחרים |
| משפט "מה לעשות היום" | תוכניות 4 שבועות |
| שמות הרעיונות מתחת לסף + ציון | 14 הסעיפים |
| לינק לדף המלא | הכל היתר |

**אם אין רעיון מעל 70 — ההודעה אומרת את זה בשורה הראשונה.**
אסור לארוז סבב חלש כאילו יש בו משהו.
