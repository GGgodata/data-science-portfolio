# המשוב שלי לסוכן

**זה הקובץ הכי חשוב במערכת.** הסוכן קורא אותו בתחילת כל ריצה, והוא גובר על כל כלל אחר.
כתוב כאן חופשי — משפט אחד מספיק. ככל שתסביר *למה* דחית, כך הריצה הבאה תהיה מדויקת יותר.

## איך לכתוב

```
### <תאריך> — <שם הרעיון מהדוח>
פסק דין: מעניין / דחוי / מתחיל לבצע
למה: <משפט או שניים. ה"למה" שווה יותר מהפסק דין עצמו.>
```

## הנחיות קבועות לסוכן

כתוב כאן דברים שתקפים לכל הריצות — הסוכן מתייחס אליהם כהוראה, לא כהצעה.
